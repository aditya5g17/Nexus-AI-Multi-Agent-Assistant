# Nexus-AI-Multi-Agent-Assistant
A LangGraph-powered Multi-Agent Intelligent Assistant with RAG, Tool Calling, Conversational Memory, and intelligent query routing.
Nexus AI is a LangGraph-powered multi-agent intelligent assistant that intelligently routes user queries to specialized agents for general conversations, knowledge retrieval, and external tool execution.

✨ Features
🧠 Intelligent Query Routing
🤖 Multi-Agent Architecture
📚 RAG-based Knowledge Retrieval
🔧 Tool Calling & Web Search
💬 Conversational Memory
⚡ Real-time AI Responses
